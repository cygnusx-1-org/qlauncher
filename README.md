Q Launcher is a [Projectivy](https://github.com/spocky/miproja1) work alike, and a free and open-source Android TV launcher.

### Features
- Reddit wallpapers, requiring Reddit login, any account will do 
- Ability to load icons from GitHub repositories 
- Ability to load Projectivy backups
- Ability to backup and restore using password protected zips

## Device support
> [!IMPORTANT]  
> Starting in October 2025 new Amazon FireTV devices no longer run Android under the hood. Q Launcher will **not** be compatible with the Fire Stick 4k Select and newer devices which run Amazon's own VegaOS.

* **Supported:** all Android TVs and TV boxes (incl. All FireTV devices released before Oct. 2025, NVIDIA Shield & Chromecast with Google TV), even older ones with Android 7.0 (Nougat).
* **Not supported:** Smartphones, non-Android platforms like Samsung Tizen, LG webOS, Apple TV, etc.

## Compatibility
Q Launcher requires Android 7.0 or above. It does not work on non-Android devices (incl. LG or Samsung TVs). On unsupported TVs, you can use a TV stick or TV box. Though this app technically runs on smartphones and tablets, it is not optimized for such and offers no official support!

## Support
You can report in our Discord group, using `Settings > Debugging > Submit data` in `Q Launcher`, or via [issue tracker on Github](https://github.com/cygnusx-1-org/qlauncher/issues) (account required).
